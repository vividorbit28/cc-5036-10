              键盘与遮挡规则

              • 列表顺序：按当前列表排序逐项移动；↑/← 上一项，↓/→ 下一项，Home/End 到端点。
              • 空间邻接：在屏幕投影上，选择按键方向夹角 ≤ 45° 且投影距离最近的对象；若距离并列，按稳定 ID 排序。默认排除隐藏对象，可用 H 或复选框纳入。
              • 遮挡：鼠标点击优先选择最近层；详情面板列出同屏重叠栈，可逐层选择。F 或“受控定位”会用受限角度移动相机以分离对象。
              • 相机：选择对象默认不移动视角；“保持视角”完全不动；“轻柔平移”是有位移上限的轻微平移；“限幅环绕”每次聚焦最多旋转 8°。所有移动都经过缓动，不会因按键突然大幅旋转，并可在视图左下角看到当前策略与动画状态。
              • 焦点由稳定 ID 绑定，不由列表位置决定；排序或反向不会把高亮交给另一个对象。
